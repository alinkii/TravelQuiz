# TravelQuiz (Вікторина подорожей)

Це Android-додаток, створений на мові Kotlin з використанням XML-макетів. 
Додаток являє собою вікторину на тему подорожей.

## Функціонал:
- 5 питань з 4 варіантами відповідей.
- Випадкова вибірка 4 питань для кожного проходження.
- Підрахунок балів за правильні відповіді.
- Підсвічування правильних та неправильних відповідей.
- Графічна кнопка переходу до наступного питання.

## Технології:
- Kotlin
- Android Studio
- XML Layouts
